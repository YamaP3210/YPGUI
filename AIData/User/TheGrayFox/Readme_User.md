# TheGrayFox

This is the local user data folder for the MVF master user.

At the current stage, MVF itself and application-side work are both being
performed by `TheGrayFox`.
Even so, the information categories must still be kept conceptually separate:

- MVF framework development belongs to `AIData/Master`
- MVF usage guidance belongs to `AIData/MVF`
- user-local preferences and notes belong here

This folder should store only user-specific local operating context.
